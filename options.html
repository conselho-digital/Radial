Radial

Radial menu settings

How to open the menu

Pick a mouse button and/or a key. Changes are saved instantly.

Mouse button

How long to hold the right button before the menu opens. Moving the mouse before that cancels.

Custom key
None

Combine with Ctrl, Alt or Shift. Without Ctrl/Alt, the key doesn't work in text fields.

Release to activate

With a mouse button as the trigger, hold, drag to the option and release: it activates without clicking. Releasing on the center switches to the next group.

The armed option stays highlighted. Going back to the center disarms it.

Cancel button

Clicking with this button while the radial is open closes the menu without activating anything (with the left button, clicking a slice no longer activates it; use release to activate). It can't be the same button as the trigger.

Scales the whole menu (slices and text). Default: 380 px.

Scales the icons and text inside each option. The size of the whole menu is separate. Default: 150%.

Chrome shortcut
Default: Alt + Shift + R

Works together with the triggers above. It is the only way to change this shortcut.

On Mac, holding the right button disables the native right-click menu while it is on.

Bookmarklets

Paste the code and give it a name. Optionally record a keyboard shortcut to run it on any page. You can also show it in the radial.

Automatic status

On the sites below, whenever your status is Do not disturb (no calls), the extension shows it as Available on your screen. If the presence button shows Available, it switches you to Do not disturb. Hold Shift while choosing Available to get the real Available. Any other status is shown as it is.

Changes apply right away. Pages already open may need a refresh.
