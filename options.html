Radial

Configurações do menu radial

Como abrir o menu

Escolha um botão do mouse e/ou uma tecla. As mudanças são salvas na hora.

Botão do mouse

Quanto tempo manter o botão direito pressionado até o menu abrir. Mover o mouse antes disso cancela.

Tecla própria
Nenhuma

Combine com Ctrl, Alt ou Shift. Sem Ctrl/Alt, a tecla não funciona em campos de texto.

Soltar para ativar

Com botão do mouse como gatilho, segure, arraste até a opção e solte: ela é ativada sem clicar. Soltar no centro ou fora do anel deixa o menu aberto para clicar.

A opção "armada" fica destacada. Voltar ao centro do anel desarma.

Botão para cancelar

Clicar com este botão enquanto o radial está aberto fecha o menu sem ativar nada (com o esquerdo, clicar numa fatia deixa de ativá-la; use soltar para ativar). Não vale o mesmo botão do gatilho.

Aumenta o menu inteiro (fatias e textos). Padrão: 380 px.

Atalho do Chrome
Padrão: Alt + Shift + R

Funciona junto com os gatilhos acima. É o único jeito de mudar esse atalho.

No Mac, segurar o botão direito desativa o menu nativo do botão direito enquanto estiver ligado.

Bookmarklets

Cole o código, escolha um atalho de teclado e pronto: ele roda em qualquer página. Se quiser, também aparece no radial.

Adicionar opção ao radial

Grave um atalho de teclado que o radial pressiona por você, ou use um código JavaScript. Também dá para criar pelo ícone da extensão, direto no site.
